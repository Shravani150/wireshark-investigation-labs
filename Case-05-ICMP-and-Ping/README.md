# Case 05 – ICMP & Ping Analysis

## Objective

Capture and analyze ICMPv6 Echo Request and Echo Reply packets generated by the `ping` command and understand how ping works at the network layer.

---

## Evidence

* `icmp-ping-example.pcapng`

Traffic generated using:

```cmd
ping example.com -n 4
```

---

# Step 1 – Filter ICMP Traffic

Display filter:

```text
icmp || icmpv6
```

# Step 4 – Round-Trip Time

### Request Time

```text
11.843284600
```

### Reply Time

```text

```

### Calculation

```text
11.852143800 - 11.843284600

```

The round-trip time for the first ping was approximately **8.86 ms** (shown directly in delta time column).

---

# Step 5 – Protocol Identification

### Does ping use TCP or UDP?

**Neither.**

Ping uses **ICMPv6**, which is a network-layer control protocol carried directly inside IPv6.

Because no TCP protocol is used, no TCP handshake appears in the capture.

---

# Step 6 – Packet Stack

```text
Frame
└── Ethernet II
    └── IPv6
        └── ICMPv6 Echo Request
```

This demonstrates protocol encapsulation from Layer 2 to Layer 3.

---

# Step 7 – Why No Ports?

ICMPv6 is not a transport-layer protocol, so it has **no source or destination ports**. TCP and UDP ports exist only in transport-layer headers, which are absent in ICMP packets.

---

# Step 8 – Troubleshooting Thought Experiment

If Echo Requests were present but Echo Replies were absent, possible causes include:

1. The destination host is down.
2. A firewall is blocking ICMP Echo Replies.
3. A routing problem exists between the source and destination.

A missing reply does not always mean the host is completely unreachable.

---

# ICMPv6 Type Values

| Message      | Type  |
| ------------ | ----- |
| Echo Request | `128` |
| Echo Reply   | `129` |

The reply type is one value higher than the request type.

---

# Investigation Conclusion

The capture showed a successful ICMPv6 ping exchange. The Echo Request and Echo Reply matched through their Identifier and Sequence Number fields, and the measured round-trip time was approximately **8.86 ms**. The investigation also demonstrated that ping operates directly over IPv6 using ICMPv6 rather than TCP or UDP.

---

# Key Learnings

* Ping uses **ICMPv6**, not TCP or UDP.
* ICMPv6 is carried directly inside IPv6.
* ICMP packets do not contain ports.
* Echo Request and Reply are matched using Identifier and Sequence Number.
* Round-trip time is measured from request to reply.
* ICMP is primarily a network-layer control protocol used for diagnostics and troubleshooting.
